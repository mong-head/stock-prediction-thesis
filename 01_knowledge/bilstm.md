# BiLSTM (Bidirectional LSTM)

> [← 개념 목록](README.md) · 관련 : [LSTM](lstm.md)

## 내 정리
- LSTM 확장형
- 시간에 따라서 앞이 아닌 뒤로 가는게 있는거에 대한거

## 보충 설명
> 🤖 Claude 설명을 확인하고 추가함

**BiLSTM = LSTM 두 개를 반대 방향으로 돌려서 합친 것**
```
정방향 LSTM:  1일 → 2일 → … → 30일    (과거부터 읽기)
역방향 LSTM:  30일 → 29일 → … → 1일   (최근부터 거꾸로 읽기)
                    ↓
          두 결과를 이어 붙여서(concat) 사용
```

- **왜 좋은가** : "나는 ___를 먹었다. 빨갛고 아삭했다." → 빈칸을 맞히려면 **뒤 문장**을 봐야 함. 앞에서만 읽으면 모르는 걸 뒤에서도 읽어서 알아냄. 그래서 번역·문장 분석처럼 **문장 전체가 주어지는** 일에서 많이 씀

### ⚠️ 주가 예측에서는 미래를 보는 게 아닌가?
- 입력이 "과거 30일"이면, 역방향은 **그 30일 안에서만** 30일 → 1일로 거꾸로 읽음 → 전부 과거 데이터라 **미래를 훔쳐보는 건 아님**
  - 비유 : 지난 한 달 차트를 왼쪽부터도 보고 오른쪽부터도 보는 것
- 단, 잘못 구현해서 윈도우 밖 미래까지 역방향에 들어가면 **데이터 누수**
- 📌 논문 읽을 때 확인 : 역방향 입력이 **입력 윈도우 안에서만** 도는가?
