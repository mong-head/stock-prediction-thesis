## 📝 읽기 노트

### 논문 요약

- 주식 시장 예측을 위한 머신러닝부터 딥러닝 연구 검토 (특히 딥러닝 17-19년도 논문 검토)
  - 성능 좋았던 머신러닝 : SVM, Random Forest등
    - 현재는 딥러닝 성능평가를 위한 baseline으로 사용됨
  - 딥러닝 : FNN, CNN, RNN, LSTM, 하이브리드 모델(CNN + LSTM 등)
- 주식 시장 예측에 있어 주된 연구 방향
  - 연구 과제
    - 회귀(가격예측) 및 분류(상승/하락)
  - 예측 과제
    - 일일 예측 > 장중 예측 (데이터량 차이)
  - 데이터 소스
    - 시장 데이터 > 텍스트 데이터(sns,뉴스 등) >>> 분석 데이터 (데이터량  및 비용차이)
    - 보통 1년 미만의 데이터 사용
  - 데이터 처리
    - 보통 하는 방식
      - 노이즈 제거, 특징추출, 차원 축소, 정규화, 차원 축소, 데이터 분할
    - 잘 사용하지 않는 방식
      - 결측치 보완, 데이터 증강
  - 예측 모델
    - 전통 모델 : FNN, CNN, RNN, LSTM
    - 하이브리드 모델 : CNN + LSTM등
    - 모델 성능 비교시 baseline 두며 보통 머신러닝 성능과 비교
  - 모델 평가
    - 분류문제 : 정확도, f1 score > precision, recall, MCC
    - 회귀문제 : RMSE, MAPE > MAE, MSE
- 향후 연구 가능 방향
  - 새로운 모델 : GAN, attention, BERT등 적용 연구
  - 다중 데이터 소스 (시장데이터 외)
  - 교차 시장 분석 (미국뿐만 아닌 범용)
  - 거래비용 고려 필요

### Overview

연구 수집 : Google Scholar 에서 아래 키워드로 검색

- deep learning
- stock prediction
- stock forecasting

연구 초점 : 개별 주식 및 시장 지수 종가 예측

- 다루는 것 : ETF, 주가 지수 선물, 호가창 중간가격 예측
- 다루지 않는 것 : 채권 가격, 암호화폐
- 연구 방향
  - 특정 값 예측 -> 회귀 문제
  - 가격 변동 방향 (상승/하락) -> 분류
- 대부분의 연구 동향
  - 일일 예측 고려
    - 일일 과거 가격과 뉴스 제목은 연구를 위해 수집하고 처리하기 쉬움
  - 5분 혹은 시간 단위 미세한 움직임 예측같은 장중 예측은 소수
    - 장중 데이터는 학계에서 매우 제한적

예측 문제 성격 4가지

- 일일 분류 : 52건
- 일일 회귀 : 54건
- 장중 분류 : 8건
- 장중 회귀 : 11건

어떤 데이터 주로 활용 하는가

- 미국 시장 지수들 (S\&P 500, 다우존스, 나스닥 등) 상당 비중
- 아시아 시장도 좀 있긴함 (중국/홍콩) > 신흥시장(미국외) 에서 모델 성능 확인용 연구로 보임
- 과제
  - 국가별 거래규정/시장환경이 달라서 한 시장에서 입증된 모델이 다른 시장에서도 동일한 성능 낼 수 있는지의 "범용성" 관련 과제가 중요한 연구과제
  - 최근 연구 방향(AI생각) : 지역적 차이 극복을 위해 다국가 데이터 결합 or 시장간의 상관관계를 그래프 구조로 학습하는 graph neural networks 등 도입하는 방향으로 발전

### 예측 워크 플로우

- 플로우 : 원시 데이터 > 데이터 처리 > 예측 모델 > 모델 평가
- 원시 데이터
  - 데이터 종류 : 내재적(과거 가격)/외생적(시장 데이터, 기술적 지표, 위키피디아 트래픽, 구글 뉴스 수 등)
  - 데이터 유형 7가지
    - 시장 데이터 : 거래량, 시가/고가/저가/종가
    - 텍스트 데이터 : 뉴스/소셜미디어 등 개인이 기여한 텍스트. 수집 및 처리 어렵지만 시장데이터 불포함된 유용한 정보 제공 가능
    - 거시경제 데이터 : 특정 국가/지역 경제상황 (소비자 물가 지수(CPI), 국내 총생산(GDP))
    - 지식 그래프 데이터 : graph neural network (그래프 신경망) 서로다른 기업-시장사이 일종 관계 있으며, 같은 부문 속한 주식 움직임은 동일 뉴스에 영향받을 수 있음
    - 이미지 데이터: 캔들스틱 차트 이용 가능
      - 위성 및 cctv 도 이용가능하지만 수집비용 높고 개인정보유출 이슈로 논문에서 안쓰임
    - fundamental data : 분기별 보고되는 회계 데이터 (자산,부채).
      - 보고빈도 낮고 날짜 부정확성으로 인해 딥러닝 모델 사용 연구에서 덜 쓰임
    - 분석 데이터 : 투자 은행/리서치 기업이 제공하는 보고서 (주식 매도 또는 매수 추천)에서 추출하는 데이터.
      - 비즈니스 모델, 활동,경쟁에 심층적인 분석 수행
        - 비용이 많이 들 수 있음
  - 딥러닝에 좋은 데이터?
    - 데이터 샘플이 많은 데이터 (방대한 양의 입력데이터 필요)
    - 1순위 : 시장데이터
    - 2순위 : 소셜미디어, 온라인 뉴스, 웹크롤러로 텍스트 데이터 쉽게 얻을 수 있음
    - 거의 미사용 : 분석 데이터; 희소성 및 높은 접근 비용
  - 데이터 길이
    - 길이 선택에 따른 tradeoff 존재
    - 짧은 기간은 과적합
    - 긴 기간은 시대에 뒤떨어질 수 있음
    - 대부분은 1년 미만 기간의 데이터 활용
  - 데이터 증강 기법 > 시계열에서는  잘 안씀
- 데이터 처리
  - 결측치 보완
    - 결측치 문제는 다른 분야에 비해 심하지 않음
    - 방법
      - 순방향 방식(forward way)으로 낮은 샘플링 빈도 데이터 삽입 필요
        - 미래 정보 데이터 누출 방지
  - 노이즈 제거
    - 주식 거래과정내 많은 비합리적 행동으로 인한 노이즈 많음
    - 방법
      - wavelet transform
      - knn 분류기
  - 특징 추출
    - 머신러닝 모델
      - 특징공학
    - 시장 데이터
      - 이동 평균
      - MACD (이동 평균 수렴 확산 지수)
    - 텍스트 데이터
      - 자연어 처리 딥러닝 모델로 발전됨
      - BoW (Bag-of-Words)
      - word embedding
      - word2vec
      - Stock2Vec
      - LIWC
    - 지식 그래프데이터
      - TransE
  - 차원 축소
    - PCA
      - PCA-ANN > FRPCA, KPCA
    - ICA
    - 제한된 볼츠만 머신
    - EMD
  - 특성 정규화 및 표준화
    - 서로 다른 척도 가진 입력 데이터에 대해 특성 정규화 및 표준화
    - 보통 0\~1 / -1 \~1 로 조정
    - z-score
  - 데이터 분할
    - k-fold : k-1개는 학습, 마지막은 테스트
    - 롤링(/슬라이딩/이동/워크플로우) 윈도우
  - 데이터 증강
    - 주가예측에선 덜 쓰임
- 모델
  - 예측 모델
    - 대부분은 지도 학습
    - 많이 사용하는 표준 모델 : cnn, rnn, feedforward neural network
    - 성능 비교를 위해 머신러닝 baseline 비교 기준을 두었음.
      - 로지스틱 회귀, ARIMA, SVM 등
  - 하이브리드 모델
    - 딥러닝 모델 + 전통적인 모델 연구도 존재
    - LSTM + CNN
    - CNN + RNN
    - LSTM 오토인코드 + 스택형 LSTM
    - GNN
  - 최근 추이
    - 기존 RNN 모델이 가장 많이 사용되었지만, 2019년이후 새모델 등장으로 그 비율 감소
- 모델 평가
  - classification metrics (분류지표)
    - 분류문제일 경우 사용
    - 정확도, 정밀도, 재현율,f1 score 등
    - 가장 많이 사용되는것 : 정확도, f1 score > precision, recall, MCC
  - regression metrics (회귀지표)
    - 회귀 문제일 경우 사용
    - 지수/주식 가격 예측 대한 모델 성능 측정
    - MAE, RMSE, MSE 등
    - 가장 많이 사용되는 것 : RMSE, MAPE > MAE, MSE

### 향후 연구 방향

- 새로운 모델
  - 보통은 예측모델 / 데이터처리 단계에서 여지가 있고,
  - GAN, attention mechanism 등 새로운 모델 적용하려는 최신 노력 존재하지만 앞으로도 다른 가능성 존재
  - BERT : 텍스트 데이터 감정 분석위해 고안된 모델이며 금융 뉴스 분석에서는 덜 논의됨
- 다중 데이터 소스
  - 시장데이터 단일로만은 성능이 좋지 않으며 다른 소스 추가로 하는게 좋음
- 교차 시장 분석
  - 미국 주식 시장뿐만 아닌 범용화 관련
- 알고리즘 트레이딩
  - 실제 거래시 거래 비용이 종종 연구시 생략되나, 고려필요함
